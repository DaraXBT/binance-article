# binance-pixel-art

Binance × Retro 8-Bit — dark crypto-native style combined with nostalgic chunky pixel art and gaming aesthetics

## Design Aesthetic

A unique fusion of Binance's structured, dark-gold identity with the nostalgic, blocky aesthetic of 8-bit/16-bit retro gaming. Isometric scenes built from chunky pixels on a deep black canvas with gold (#F0B90B) as the hero accent. The visual language relies heavily on pixel grid alignment, dithering, staircase edges, and flat color planes. Micro-people are stylized as retro sprites. Playful nostalgia meets serious crypto-native infrastructure. 

## Background

- Color: Canvas Black (#0C0E12)
- Texture: Faint 8-bit pixel grid pattern or subtle CRT scanline effect in mid-tone (#2B3139)

## Typography

BinanceNova (fallback: Arial) for standard text. Titles in Bold 700, ALL-CAPS, gold (#F0B90B). Crucial text elements integrated into the art should use chunky blocky pixelated bitmap fonts. Labels in Bold 700, ALL-CAPS, primary white (#EAECEF). Key-value pairs: category in gold, value in white, both ALL-CAPS.

## Color Palette

Strictly limited palette to emulate retro hardware constraints (16-32 colors max per scene).

| Role | Color | Hex | Usage |
|------|-------|-----|-------|
| Background | Canvas Black | #0C0E12 | Primary background, essential |
| Card Surface | Dark Gray | #1E2329 | Platform surfaces, card fills |
| Mid-tone | Border Gray | #2B3139 | Pixel borders, grid lines, dithering |
| Hero Accent | Binance Gold | #F0B90B | Hero sprites, active fills, primary focus |
| CTA / Alert | Bright Gold | #FCD535 | Highlights, active connectors |
| Primary Text | Light Gray | #EAECEF | Primary labels, bright pixel highlights |
| Secondary Text | Muted Gray | #707A8A | Secondary labels, shadows |
| Positive Action | Pixel Green | #02C076 | Growth, success elements, up arrows |
| Alert / Danger | Pixel Red | #F6465D | Warnings, loss, down arrows |

## Visual Elements

- **Pixelated Isometric scenes** at 30° angle. Forms must have staircase diagonal edges. No anti-aliasing or smooth 3D rendering.
- **Floating platforms**: slabs, cylinders, blocks constructed on a strict pixel grid. Base fill #1E2329, pixel border #2B3139. Hero platform top-face in blocky gold #F0B90B.
- **BNB mark**: 4-pointed star ◆ rendered as a chunky 8-bit sprite. Gold on dark surfaces.
- **Topic icons**: rendered as 8-bit retro sprites (coin, chart, wallet, shield). Single or double-pixel outlines.
- **Data elements**: pixelated bar charts, chunky progress bars, staircase trend lines. Dithering patterns used instead of smooth gradients for color transitions.
- **Micro-sprites (People)**: 8-bit character sprites, 3–5 per scene max. Blocky anatomy. Clothing in gold, white, and muted gray. Always standing ON pixel platforms.
- **Retro UI**: text bubbles with pixel borders, floating geometric shapes, classic RPG menu elements serving as callout boxes.

## Style Rules

### Do

- Maintain strict pixel grid alignment throughout the entire scene
- Use Canvas Black (#0C0E12) as the background — never light
- Use gold (#F0B90B) exclusively as the hero accent
- Limit the color palette severely (rely heavily on dithering for shading)
- Use staircase edges for diagonals and curves
- Include the BNB mark rendered as a pixel sprite
- Keep character sprites blocky and nostalgic

### Don't

- Use smooth gradients, soft drop shadows, or anti-aliasing
- Create photorealistic or high-resolution vector curves
- Break the pixel grid or use sub-pixel rendering
- Use colors outside the defined limited palette (no bright blue, purple, etc.)
- Use thin, airy lines (minimum stroke is a chunky pixel)

## Best For

Crypto gaming (GameFi), nostalgic tech retrospectives, hackathon announcements, developer-focused Web3 tutorials, community engagement posts, playful explainer content for complex blockchain mechanics.
