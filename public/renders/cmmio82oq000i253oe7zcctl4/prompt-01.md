# binance-lab-notes

Binance × Lab Notes — dark crypto-native isometric style with sparse technical annotations and research-note clarity

## Design Aesthetic

Dark, gold-led Binance isometric scenes presented like a clean annotated figure from a lab notebook or protocol memo. One hero mechanism sits at the center on a deep black canvas, with 2–4 compact labels, figure markers, or observation chips clarifying how the system works. The tone is technical and educational, but still unmistakably Binance: dark background first, gold for hierarchy, structured floating platforms, BNB mark present, and disciplined empty space. Annotation stays light and precise rather than becoming a dense briefing board.

## Background

- Color: Canvas Black (#0C0E12)
- Texture: Faint isometric dot grid using mid-tone (#2B3139); optional ultra-subtle diagram ticks or registration marks at 2–3% opacity in #1E2329; never paper texture, never cream

## Typography

BinanceNova (fallback: Arial). Titles in Bold 700, ALL-CAPS, gold (#F0B90B). Core labels in Bold 700, primary white (#EAECEF), +0.04em tracking. Technical note labels in Regular 500–600, primary white or muted gray (#B7BDC6 / #707A8A), 12–13px, concise and single-line where possible. Figure markers, chip labels, and note tags use compact uppercase text with tight padding and 1px borders. Bilingual labels are optional only when the content truly requires them; default to single-language labels so the layout stays cleaner than a briefing poster.

## Visual Elements

- **Hero isometric mechanism**: one central 30° isometric explanation scene occupying ~45–55% of the canvas; flat fills, ground shadows only, no photoreal 3D
- **Floating platforms**: slabs, cylinders, rounded blocks on iso-grid; base fill #1E2329, border 1px #2B3139, active border 1px #FCD535; hero platform top-face in gold #F0B90B
- **BNB mark**: 4-pointed star ◆ or 5-square diamond grid; placed on hero platform, top-left header, or subtle scene anchor; always one per scene; gold on dark or #0C0E12 on gold — never recolored
- **Topic icons**: one icon per platform matching the input theme; outlined 2px stroke; #FCD535 on dark surfaces, #0C0E12 on gold surfaces; drawn from Binance vocabulary (coin, chart, wallet, swap, shield, bridge, contract, globe, candlestick, arrow, lock, QR, DAO)
- **Technical note tags**: 2–4 compact labels, observation chips, or figure markers placed around the main mechanism; fill #1E2329, border 1px #2B3139 or #FCD535 for emphasis; text is short, factual, and diagram-adjacent rather than paragraph-like
- **Leader lines**: thin 1px solid or lightly dotted lines in #707A8A connecting note tags to exact mechanism points; route cleanly along 90° turns or iso-axes
- **Figure markers**: small numbered markers, step badges, or micro-tags in #FCD535 used sparingly to sequence the explanation without turning the scene into a poster board
- **Support panels**: optional narrow footer strip, side note, or mini key insight chip for one takeaway only; not the defining motif and never larger than the hero mechanism
- **Data elements**: compact charts, arrows, and flow indicators integrated into the mechanism; gold remains primary, with green/red used only for data states
- **Micro-people**: flat filled, zero outlines, 2–4 per scene max; mixed skin tones (#5C3D2E, #C68642, #F5CBA7); purposeful analytical poses (pointing, inspecting, routing, verifying); always standing ON platforms, never floating
- **Composition**: preserve one hero mechanism with annotation orbiting it; prefer one main scene plus sparse note framing over split-board or briefing-wall layouts; 8px base grid with all gaps ×8; dark empty space is intentional

## Style Rules

### Do

- Always use dark background (#0C0E12) — never light
- Keep Binance gold (#F0B90B) as the primary hierarchy signal
- Preserve one hero isometric mechanism or system explanation at the center
- Include BNB mark in every scene (one per scene)
- Place a topic-relevant icon on every platform
- Use 2–4 compact technical note labels, not dense text blocks
- Keep annotation sparse, precise, and anchored to specific parts of the diagram
- Default to single-language labels; use bilingual labels only when the content requires them
- Use key insight panels only as optional support elements
- Align all elements to 8px grid
- Let dark empty space breathe — it is part of the style
- Replace all nouns with input theme nouns (theme wins over style)
- Keep micro-people diverse and purposeful

### Don't

- Use cream, paper, parchment, or any light background treatment
- Turn the layout into a full research poster or dense briefing board
- Use 3–6 large callout boxes as the dominant motif
- Make bilingual labels mandatory or visually dominant
- Let key insight panels overpower the central mechanism
- Split the scene into multiple equal boards unless the topic explicitly requires it
- Add decorative annotation without explanatory function
- Use teal as a competing accent system
- Use rounded LEGO-style fonts
- Place people floating mid-air
- Add office/meeting/investor imagery unless explicitly in theme

## Best For

Protocol explainers, exchange mechanics, DeFi system breakdowns, workflow visualizations, token flow education, Web3 research-note figures, annotated mechanism diagrams, lighter-weight technical education on crypto-native topics
