# binance-blueprint

Binance × Blueprint — dark technical schematic style with isometric architecture diagrams and gold engineering lines

## Design Aesthetic

Dark-mode engineering schematic meets crypto-native Binance identity. Isometric architecture diagrams drawn with blueprint precision on a deep black canvas. Gold (#F0B90B) replaces traditional engineering blue as the hero line color — dimension lines, cross-sections, and measurement indicators all rendered in Binance gold. Floating platforms become technical schematics with annotated specifications. Micro-people operate as engineers inspecting and measuring systems. Every element snaps to an 8px isometric grid with engineering-grade alignment. The result feels like an architect's blueprint for decentralized infrastructure — precise, structured, and unmistakably Binance.

## Background

- Color: Canvas Black (#0C0E12)
- Texture: Faint engineering grid in mid-tone (#2B3139), thin 1px lines at 8px intervals visible on isometric axes; grid intersections marked with subtle dots; no decorative noise

## Typography

BinanceNova (fallback: Arial). Titles in Bold 700, ALL-CAPS, gold (#F0B90B). Dimension labels in Mono 500, ALL-CAPS, #EAECEF, +0.08em tracking — placed along measurement lines. Annotation callouts in Regular 400, #707A8A, 12–13px, line-height 1.4. Spec values on same line: label in gold, value in white, both ALL-CAPS. All text snaps to grid.

## Visual Elements

- **Isometric schematics** at 30° angle with engineering-grade line precision; all lines consistent 1.5px stroke weight; flat color fills with ground shadows only — no 3D rendering
- **Floating platforms as blueprints**: each platform drawn with visible edge dimensions and spec callouts; base fill #1E2329, border 1px #2B3139, active border 1px #FCD535; hero platform top-face in gold #F0B90B with dimension lines extending from edges
- **Dimension lines**: gold (#F0B90B) lines with perpendicular end-caps extending from platform edges, connectors, and data elements; measurement values in #EAECEF mono text
- **Cross-section views**: cut-away diagrams showing internal structure of protocols, smart contracts, or blockchain layers; cut lines dashed in #FCD535; fill sections alternate #1E2329 and #2B3139; labeled with gold callout arrows
- **Connection lines**: straight or 90-degree angles only — never curved; gold (#FCD535) solid with rounded tips routing along iso-grid; junction dots at line intersections; direction arrows at endpoints
- **BNB mark**: 4-pointed star ◆ or 5-square diamond grid; placed on hero platform or top-left spec cartouche; always one per scene; gold on dark or #0C0E12 on gold — never recolored
- **Topic icons**: one icon per platform matching the input theme; outlined 2px stroke in technical-drawing style; #FCD535 on dark surfaces, #0C0E12 on gold surfaces; drawn with geometric precision — no organic shapes
- **Data elements**: bar charts with engineering grid overlay; donut charts rendered as cross-section pie diagrams; trend lines in #FCD535 with labeled data points; engineering blue (#2563EB) used for secondary data series
- **Micro-engineers**: flat filled, zero outlines, 2–4 per scene max; mixed skin tones (#5C3D2E, #C68642, #F5CBA7); wearing hard hats, holding measuring tools, pointing at specs; purposefully inspecting or annotating; always standing ON platforms, never mid-air
- **Spec cartouche**: optional corner box (top-left or bottom-right) with 1px #FCD535 border containing: BNB mark, topic title, and 2–3 key specs as label:value pairs
- **Composition**: left→right for process/data flow, bottom→top for layer hierarchy; 3 depth layers with foreground larger; max 4 platforms; dark empty space is intentional — no decorative fill; 8px base grid with all gaps ×8; every line segment must align to isometric axes or be exactly horizontal/vertical

## Style Rules

### Do

- Always use dark background (#0C0E12) — never light
- Include BNB mark in every scene (one per scene)
- Add dimension lines with measurement values on key elements
- Place topic-relevant icons on every platform — drawn with geometric precision
- Align ALL elements to 8px isometric grid — no off-grid placement
- Use gold (#F0B90B) as hero line color; engineering blue (#2563EB) as secondary only
- Include at least one cross-section or cutaway view per scene
- Use 90-degree or iso-axis-aligned connection lines only
- Maintain consistent 1.5px stroke weight across all technical lines
- Let dark empty space breathe — it's intentional
- Replace all nouns with input theme nouns (theme wins over style)

### Don't

- Use light gray, white, or any light background
- Use curved, wavy, or organic connection lines
- Add hand-drawn or sketchy elements — everything must be geometrically precise
- Have more than 3 gold-topped platforms in one scene
- Add decoration without function — every line must serve a purpose
- Use rounded LEGO-style fonts
- Omit dimension annotations — platforms without specs look unfinished
- Place people floating mid-air
- Add office/meeting imagery unless explicitly in theme
- Let engineering blue overpower gold — gold leads, blue supports
