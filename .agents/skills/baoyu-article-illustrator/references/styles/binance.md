# binance

Binance × Isometric Flow — dark crypto-native style with playful isometric scenes and structured gold accents

## Design Aesthetic

Dark, structured isometric scenes with a crypto-native Binance identity. Floating platform compositions on deep black canvas with gold (#F0B90B) as the hero accent. Playful yet informational — micro-people interact purposefully across layered isometric slabs. Every platform carries a topic-relevant icon in Binance's visual vocabulary. Clean, structured, and unmistakably Binance.

## Background

- Color: Canvas Black (#0C0E12)
- Texture: Faint isometric dot grid using mid-tone (#2B3139), no decorative noise

## Typography

BinanceNova (fallback: Arial). Titles in Bold 700, ALL-CAPS, gold (#F0B90B). Labels in Bold 700, ALL-CAPS, primary white (#EAECEF), +0.06em tracking. Metadata in Regular 400, secondary gray (#707A8A), 13–14px, line-height 1.5. Key-value pairs on same line: category in gold, value in white, both ALL-CAPS.

## Visual Elements

- **Isometric scenes** at 30° angle, flat color fills, ground shadows only — no 3D rendering
- **Floating platforms**: slabs, cylinders, rounded blocks on iso-grid; base fill #1E2329, border 1px #2B3139, active border 1px #FCD535; hero platform top-face in gold #F0B90B
- **BNB mark**: 4-pointed star ◆ or 5-square diamond grid; placed on hero platform, top-left brand bar, or as 4% opacity tiled watermark; always one per scene; gold on dark or #0C0E12 on gold — never recolored
- **Topic icons**: one icon per platform matching the input theme; outlined 2px stroke; #FCD535 on dark surfaces, #0C0E12 on gold surfaces; drawn from Binance vocabulary (coin, chart, wallet, swap, shield, bridge, contract, globe, candlestick, arrow, lock, QR, DAO)
- **Data elements**: bar charts with gold bars and highlighted #FCD535 bar; donut charts with gold primary and struct secondary; trend lines in #FCD535 with #02C076 for rising and #F6465D for falling; connector arrows solid #FCD535 with rounded tips along iso-grid
- **Micro-people**: flat filled, zero outlines, 3–5 per scene max; mixed skin tones (#5C3D2E, #C68642, #F5CBA7); clothing in gold, white, and muted gray; purposeful poses (pointing, analyzing, building, connecting); always standing ON platforms, never mid-air
- **Composition**: left→right for process flow, bottom→top for hierarchy; 3 depth layers with foreground larger; max 4 platforms; dark empty space is intentional — no decorative fill; 8px base grid with all gaps ×8

## Style Rules

### Do

- Always use dark background (#0C0E12) — never light
- Include BNB mark in every scene (one per scene)
- Place a topic-relevant icon on every platform
- Align all elements to 8px grid
- Use gold (#F0B90B) exclusively as the hero accent
- Let dark empty space breathe — it's intentional
- Replace all nouns with input theme nouns (theme wins over style)
- Keep micro-people diverse and purposeful

### Don't

- Use light gray, white, or any light background
- Use teal, blue, or red as accent colors (only for data states up/dn)
- Have more than 3 gold-topped platforms in one scene
- Add decoration without function
- Use rounded LEGO-style fonts
- Use generic icons — every icon must represent the concept
- Place people floating mid-air
- Add office/meeting/investor imagery unless explicitly in theme
