# binance

Dark crypto-native style with gold accents focused on conveying Web3 topics through structured visuals.

## Color Palette

| Role | Color | Hex |
|------|-------|-----|
| Primary Background | Canvas Black | #0C0E12 |
| Surface Dark | Dark Gray | #1E2329 |
| Surface Light / Borders | Border Gray / Neutral | #2B3139 / #3D3D3D |
| Hero Accent | Binance Gold | #F0B90B |
| CTA / Active | Bright Gold | #FCD535 |
| Primary Text / UI | Light Gray | #EAECEF |
| Secondary Text | Muted Gray | #707A8A |
| Positive Indicator | Green | #02C076 |
| Negative Indicator | Red | #F6465D |

## Decorative Hints

- Use canvas black strictly as the background, never light.
- Limit gold to hero elements, active fills, and section titles to ensure focus.
- Use a faint isometric dot grid on the background in mid-tone `#2B3139` without decorative noise.

## Best For

Cryptocurrency, blockchain, Web3 infrastructure, trading concepts, and digital asset management.
